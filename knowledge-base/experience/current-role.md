# Current Role - Senior Cloud Platform Engineer

## Position Overview

Jacob Steelsmith currently works as a Senior Cloud Platform Engineer, focusing on designing and implementing cloud-native infrastructure solutions on AWS. His role encompasses architecture design, infrastructure automation, and enabling development teams to deploy and operate services reliably.

## Key Responsibilities

### Infrastructure Architecture
- Design and implement scalable, secure AWS architectures for production workloads
- Establish infrastructure-as-code standards using Terraform across the organization
- Define networking topologies, security boundaries, and access control patterns
- Evaluate and adopt new AWS services to improve platform capabilities

### Platform Engineering
- Build and maintain shared infrastructure modules and reusable Terraform components
- Implement CI/CD pipelines with GitHub Actions and OIDC-based AWS authentication
- Design serverless architectures using Lambda, API Gateway, and event-driven patterns
- Manage container platforms with ECS/Fargate for microservice deployments

### Security and Compliance
- Implement least-privilege IAM policies and role-based access control
- Configure WAF rules, security headers, and TLS enforcement
- Establish secrets management practices using AWS Secrets Manager and Parameter Store
- Conduct security reviews of infrastructure changes and deployment pipelines

### Technical Leadership
- Mentor junior engineers on cloud architecture and IaC best practices
- Lead architecture decision records (ADRs) for significant infrastructure changes
- Collaborate with development teams to optimize application deployments
- Drive adoption of observability practices including structured logging and distributed tracing

## Technologies Used Daily
- Terraform, AWS CDK
- GitHub Actions, OIDC authentication
- AWS Lambda, API Gateway, S3, CloudFront, Route 53
- Amazon Bedrock, ECS/Fargate
- CloudWatch, X-Ray
- TypeScript, Python
