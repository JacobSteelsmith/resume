# Previous Roles and Career Progression

Prior to his current senior role, Jacob worked as a Cloud Engineer focused on migrating on-premises workloads to AWS and building foundational cloud infrastructure.

- Built CI/CD pipelines with GitHub Actions for automated testing and deployment
- Designed VPC architectures with proper network segmentation and security controls
- Established monitoring and alerting using CloudWatch metrics and alarms

### Technologies

- Terraform, CloudFormation
- Docker, ECS

- GitHub Actions
