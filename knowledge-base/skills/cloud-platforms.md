# AWS Cloud Platform Expertise

## Core AWS Services

Jacob Steelsmith is a senior cloud platform engineer with deep expertise across the AWS ecosystem. His primary focus areas include:

### Compute and Serverless
- AWS Lambda: Event-driven serverless functions for API backends, data processing, and automation
- Amazon ECS/Fargate: Container orchestration for microservices
- Amazon EC2: Instance management, auto-scaling groups, and launch templates

### Storage and Content Delivery
- Amazon S3: Static hosting, data lakes, lifecycle policies, cross-region replication
- Amazon CloudFront: CDN configuration, Origin Access Control, custom error pages, security headers
- Amazon EBS/EFS: Block and file storage for compute workloads

### Networking and Security
- Amazon VPC: Network architecture, subnets, security groups, NACLs
- AWS WAF: Web application firewall rules, rate limiting, IP-based restrictions
- AWS IAM: Least-privilege policies, OIDC federation, role-based access control
- Amazon Route 53: DNS management, alias records, health checks

### AI and Machine Learning
- Amazon Bedrock: Foundation model access, Knowledge Bases, RAG architectures
- Amazon Bedrock Agents: Conversational AI with retrieval-augmented generation

### Developer Tools and CI/CD
- AWS CodePipeline/CodeBuild: CI/CD pipeline automation
- GitHub Actions with OIDC: Keyless authentication to AWS from GitHub workflows
- AWS CloudFormation: Infrastructure as code (legacy projects)

### Monitoring and Operations
- Amazon CloudWatch: Metrics, alarms, log groups, dashboards
- AWS X-Ray: Distributed tracing for serverless applications
- AWS Systems Manager: Parameter Store, Session Manager, automation

## Certifications Context

Jacob holds multiple AWS certifications demonstrating validated expertise across solutions architecture, development, and cloud operations.
