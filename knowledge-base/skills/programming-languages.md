# Programming Languages and Development Skills

## Primary Languages

### TypeScript
Jacob's primary language for application development. Used extensively for:
- Full-stack web applications with Astro, React, and Node.js
- AWS Lambda function handlers
- Infrastructure automation scripts
- Type-safe API clients and server implementations
- Property-based testing with fast-check

### Python
Used for automation, scripting, and data processing:
- AWS Lambda functions for data pipelines
- Infrastructure automation and CLI tools
- Boto3 SDK for AWS service integration
- Testing with pytest and hypothesis

### HCL (HashiCorp Configuration Language)
Primary infrastructure-as-code language:
- Terraform modules for AWS infrastructure
- Multi-provider configurations (AWS, GitHub, Cloudflare)
- State management with S3 backends and DynamoDB locking
- Module composition and reusable infrastructure patterns

## Secondary Languages

### Bash/Shell
- CI/CD pipeline scripts
- System automation and deployment tooling
- AWS CLI scripting for operational tasks

### SQL
- Database schema design and migrations
- Query optimization for PostgreSQL and DynamoDB
- Data analysis and reporting queries

## Development Practices

- Test-driven development with unit and property-based testing
- Type-safe development with strict TypeScript configurations
- Code review and pair programming
- Documentation-driven development
- Git workflow with feature branches and pull request reviews
